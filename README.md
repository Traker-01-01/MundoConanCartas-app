# MundoConan Cartas — Descargas

Colecciona, intercambia y subasta cartas de Detective Conan con los detectives de **La Agencia**.
El juego es la web **[cartas.mundoconan.com](https://cartas.mundoconan.com)**; aquí están las apps para jugar sin navegador.

👉 **[Descargar la última versión](../../releases/latest)**

| Sistema | Archivo |
|---|---|
| **Windows** | `MundoConanCartas-Instalar-….exe` |
| **Mac** (Apple M1/M2/M3…) | `MundoConanCartas-…-mac-arm64.dmg` |
| **Mac** (Intel) | `MundoConanCartas-…-mac-x64.dmg` |
| **Linux** | `.AppImage` (cualquier distribución) · `.deb` (Ubuntu/Debian) · `.tar.gz` |
| **Android** | `MundoConanCartas-Android-….apk` |

**La primera vez:**
- **Windows** puede avisar «Windows protegió tu PC»: pulsa *Más información* → *Ejecutar de todas formas*.
- **Mac**: clic derecho sobre la app → *Abrir* (solo la primera vez).
- **Linux (AppImage)**: dale permiso de ejecución (`chmod +x`) y ábrelo.
- **Android**: al abrir el APK, permite «instalar apps de origen desconocido».

Las apps se actualizan solas: todo lo nuevo del juego llega sin reinstalar nada.

Este repositorio solo guarda los instaladores; el código del juego no es público.
